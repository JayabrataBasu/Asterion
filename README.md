# Asterion

An ASCII space shooter that runs in your browser. Fly, fight, collect scrap, upgrade at stations.

**Play:** https://jayabratabasu.github.io/Asterion/

## Controls

| Key | Action |
| --- | --- |
| W / A / D | Thrust / turn |
| S | Brake |
| Space | Fire |
| Shift | Boost |
| F | Dodge |
| X | Missile (needs upgrade) |
| E | Dock at a station |
| N | Map |
| P / Esc | Pause |

Keys can be rebound in the menu. Needs a browser with WebGL2.

## Run locally

```
npm install
npm run dev
```

Build: `npm run build` (output in `dist/`). Tests: `npm test`.
